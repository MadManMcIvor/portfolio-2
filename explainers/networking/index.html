The stack

Each protocol does one job and hands the rest to the layer below. Higher bands are closer to what your code says; lower bands are closer to the wire. Tap any protocol for details.

The textbook OSI model has seven layers; the real internet uses roughly these four, plus security, which doesn't fit neatly anywhere. TLS sits between transport and application, SSH brings its own encryption, and QUIC folds transport and TLS together. Treat the bands as a mental model, not law.

Real-time options on one timeline

The same four server-side events, delivered four different ways. In each row the top line is the browser and the bottom line is the server. Watch the gap between each dotted event line and when the browser actually finds out.

Short pollingSimple and cache-friendly, but you wait up to a full interval and most requests come back empty.
Long pollingNear-instant over plain HTTP, at the cost of a new request after every event.
Server-Sent EventsOne request, events streamed instantly, automatic reconnect. Server to browser only.
WebSocketOne connection, instant in both directions. You own reconnects and message semantics.
